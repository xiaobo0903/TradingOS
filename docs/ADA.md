1. 文档概述
1.1 系统定位

TradingOS AI智能分析系统是整个 TradingOS 平台的智能决策辅助中心。

它不是预测股票涨跌的系统，而是：

基于实时行情数据、技术指标、资金数据、市场环境、股票知识库，通过大语言模型（LLM）进行综合分析，为投资者提供专业化、结构化、可解释的股票分析报告。

1.2 AI系统目标
核心目标

将传统股票软件：

显示数据
+
显示指标

升级为：

理解数据
+
解释指标
+
分析原因
+
提示风险
+
辅助决策
