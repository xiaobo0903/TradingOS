TradingOS 股票智能分析模型设计文档 V1.0
1. 文档概述
1.1 产品定位

TradingOS 股票智能分析模型，是整个系统的大脑。

它负责：

综合股票实时行情数据
分析技术指标状态
判断股票当前阶段
识别主力资金行为
结合市场环境
调用LLM生成投资分析报告

目标：

让普通投资者能够像专业交易员一样，从：

市场环境
 ↓
行业板块
 ↓
个股状态
 ↓
资金行为
 ↓
技术指标
 ↓
买卖机会

进行系统化分析。

11. LLM智能分析层设计

LLM不是直接预测股票。

作用：

负责：

总结
推理
解释
生成报告

输入：

JSON:

{
 "price":23.5,
 "macd":"gold_cross",
 "rsi":65,
 "boll":"突破上轨",
 "volume":"放量",
 "main_force":"吸筹"
}

Prompt:

你是一名专业股票分析师。

根据提供的数据：

1. 判断股票当前阶段
2. 分析上涨或下跌原因
3. 给出风险提示
4. 给出操作建议

禁止预测确定涨跌。
必须基于数据分析。
