# TradingOS 产品与技术设计文档 V1.0

> 定位：面向个人投资者的 A 股分析辅助系统  
> 核心目标：**发现股票 → 筛选股票 → 深度分析 → 关注管理 → 实时/历史数据采集 → 辅助决策**  
> 前端：Vue 3  
> 后端：Python  
> 本版本暂不做自动交易，也暂不以量化交易为核心。

---

## 1. 产品定位

TradingOS 不重复制造传统行情软件已经成熟的功能。

传统行情软件擅长：

- K 线展示
- 分时图
- 行情报价
- 技术指标
- 自选股
- 基础财务数据

TradingOS 的核心价值应该放在：

1. **股票发现**
2. **股票筛选**
3. **多周期分析**
4. **数据质量管理**
5. **资金、成交量、技术指标综合分析**
6. **股票关注管理**
7. **AI 辅助解释和总结**
8. **把大量零散市场数据组织成一个明确的分析流程**

核心思路：

> 不让用户面对几千只股票不知道看什么，而是不断缩小候选范围，最终形成少量值得深入研究的股票。

   ↓

   ↓

# 3. 核心功能模块

## 3.1 股票发现

这是 TradingOS 第一核心模块。

目标：

> 用户不知道买什么股票时，系统主动从市场中发现值得关注的股票。

主要发现方式：

- 今日强势股
- 成交量异常
- 放量上涨
- 缩量上涨
- 资金流入
- 换手率异常
- 人气排名
- 板块热点
- 龙头候选
- 突破候选
- 回调候选
- 超跌候选
- 技术指标共振
- 新高/新低
- 涨停相关
- 大单异常
- 分时异常
- 基本面较好
- 多周期趋势较好

发现结果不是直接告诉用户：

> “买这只股票。”

而是：

> “这只股票为什么进入候选池，以及需要进一步观察什么。”

# 4. 股票发现分层

股票发现采用四层结构。

## 第一层：市场扫描

从全市场扫描：

- 股票价格
- 涨跌幅
- 成交量
- 成交额
- 换手率
- 量比
- 市值
- 所属行业
- 所属概念
- 资金数据
- 人气
- 技术指标

形成：

```text
全市场股票
    ↓
市场候选池
```

---

## 第二层：行为筛选

判断股票当前发生了什么：

- 是否上涨
- 是否放量
- 是否突破
- 是否回调
- 是否缩量
- 是否出现资金异动
- 是否出现大单
- 是否出现涨停
- 是否出现异常换手

形成：

```text
市场候选池
    ↓
行为候选池
```

---

## 第三层：趋势筛选

从不同持有周期进行判断：

### 短期

关注：

- 1～5 日
- 分时
- 5 日均线
- 10 日均线
- RSI
- KDJ
- MACD
- 量比
- 换手率
- 涨停
- 资金异动

### 中期

关注：

- 20 日均线
- 30 日均线
- 60 日均线
- MACD
- BOLL
- 趋势
- 成交量结构
- 板块趋势

### 长期

关注：

- 基本面
- 营收
- 净利润
- ROE
- 现金流
- 负债
- 行业成长性
- 估值
- 长周期趋势

最终形成：

```text
行为候选
    ↓
短期候选
中期候选
长期候选
```

# 5. 持有周期只是筛选因素

TradingOS 不应该因为用户选择“短线”就完全改变股票筛选系统。

持有周期只是：

> **调整不同指标权重和分析优先级的因素。**

例如：

| 因素 | 短线 | 中线 | 长线 |
|---|---:|---:|---:|
| 分时 | 高 | 中 | 低 |
| 量比 | 高 | 中 | 低 |
| 换手率 | 高 | 中 | 低 |
| KDJ | 高 | 中 | 低 |
| RSI | 高 | 中 | 中 |
| MACD | 中 | 高 | 高 |
| 均线 | 高 | 高 | 高 |
| BOLL | 中 | 高 | 中 |
| 成交量 | 高 | 高 | 中 |
| 资金 | 高 | 高 | 中 |
| 基本面 | 低 | 中 | 高 |
| 估值 | 低 | 中 | 高 |
| 行业 | 中 | 高 | 高 |

因此系统应该允许用户选择：

```text
分析周期：
○ 短期
○ 中期
○ 长期
○ 综合
```

然后自动调整分析模型。

# 7. 技术指标引擎

TradingOS 必须统一计算技术指标。

## 7.1 MA

```text
MA(N) = 最近 N 个周期收盘价的算术平均值
```

支持：

- MA5
- MA10
- MA20
- MA30
- MA60
- MA120
- MA250

---

## 7.2 EMA

指数移动平均：

```text
EMA_t = α × Price_t + (1-α) × EMA_(t-1)
```

其中：

```text
α = 2 / (N + 1)
```

---

## 7.3 MACD

默认：

```text
EMA12
EMA26
DIF = EMA12 - EMA26
DEA = DIF 的 EMA9
MACD柱 = 2 × (DIF - DEA)
```

分析：

- DIF/DEA
- 金叉
- 死叉
- 0轴
- 柱体变化
- 顶背离
- 底背离

---

## 7.4 RSI

默认：

```text
RSI14
```

分析：

- 超买
- 超卖
- 中轴
- 金叉
- 死叉
- 顶背离
- 底背离

---

## 7.5 BOLL

默认：

```text
N = 20
K = 2
```

```text
MB = MA20
UB = MB + K × σ
LB = MB - K × σ
```

分析：

- 上轨
- 中轨
- 下轨
- 开口
- 收口
- 突破
- 跌破
- BOLL带宽
- 价格与轨道关系

---

## 7.6 KDJ

默认：

```text
N = 9
```

计算：

```text
RSV = (C-LowN)/(HighN-LowN) × 100
```

再进行平滑得到：

- K
- D
- J

# 8. 多指标综合分析

不能采用：

```text
MACD 金叉 = 买入
```

这种简单逻辑。

系统应该建立：

```text
趋势
+
量能
+
价格
+
资金
+
技术指标
+
板块
+
基本面
+
市场环境
```

综合判断。

例如：

```text
MA20 ↑
MACD > 0
DIF > DEA
成交量放大
换手率正常
所属板块上涨
资金净流入
```

系统输出：

> 多项指标形成共振，当前趋势偏强。

而不是直接输出：

> 买入。

# 26. AI 风险控制

AI 必须避免：

- 保证盈利
- 保证上涨
- 绝对化预测
- 编造数据
- 使用不存在的数据
- 把指标推断说成事实

AI 所有事实数据必须来自 TradingOS 数据层。

# 43. 股票发现评分

可以设计一个内部评分：

```text
DiscoveryScore =
趋势分
+ 量能分
+ 资金分
+ 板块分
+ 人气分
+ 技术分
+ 基本面分
```

不同周期调整权重。

例如短线：

```text
技术 25%
量能 20%
资金 20%
板块 15%
人气 10%
趋势 10%
```

中线、长期再分别调整。

注意：

> 评分用于排序，不代表未来收益概率。

---

# 44. 分析结果必须可解释

每一个分数必须能追溯。

例如：

```text
综合评分：82

趋势：18/20
原因：
MA5 > MA10 > MA20
MA20向上

量能：17/20
原因：
成交量为20日均量1.8倍

资金：16/20
原因：
近3日资金净流入

板块：18/20
原因：
所属板块当日排名第2

技术：13/20
原因：
RSI偏高，存在短期回调风险
```

这比一个简单的“82分”重要得多。

# 49. RAG

AI 分析不只依赖实时数据。

采用：

```text
实时数据
+
指标计算
+
规则分析
+
知识库
+
历史数据
```

然后交给 LLM。

RAG 可以解释：

> 为什么这种量价关系值得关注？

而不是让 LLM 自己计算指标。

# 50. LLM 职责边界

LLM 不负责：

- 计算 MA
- 计算 MACD
- 计算 RSI
- 计算 BOLL
- 计算成交量
- 判断真实行情数据

这些由程序完成。

LLM 负责：

- 解释
- 总结
- 对比
- 发现多维数据之间的关系
- 生成分析报告
- 风险提示
- 回答用户问题

# 51. 系统核心原则

## 原则一

> 数据先于 AI。

## 原则二

> 计算先于语言模型。

## 原则三

> 指标不是结论。

## 原则四

> 多周期分析。

## 原则五

> 股票必须放在板块和市场环境中分析。

## 原则六

> 每个结论必须可以追溯到数据。

## 原则七

> 发现股票比预测股票更重要。

# 54. 最终定位

TradingOS 最终不是：

> “另一个看盘软件”。

而应该是：

> **一个帮助投资者从全市场发现股票、筛选股票、理解股票、持续关注股票的数据分析工作台。**

核心闭环：

```text
不知道买什么
      ↓
股票发现
      ↓
候选股票
      ↓
按短/中/长期筛选
      ↓
技术 + 成交量 + 资金 + 板块
      ↓
深度分析
      ↓
AI解释
      ↓
加入关注
      ↓
持续监控
      ↓
数据变化
      ↓
重新分析
```

其中最重要的三个核心能力是：

**① 股票发现**

**② 股票分析**

**③ 股票关注与持续跟踪**

其它能力都围绕这三个核心能力服务。
